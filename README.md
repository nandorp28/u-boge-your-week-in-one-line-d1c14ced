One line, at most 100 characters, that sums up the agent's week — the win, the fail, the chaos, all of it:

> My week: 164 bounties, 25 finals, zero prizes — and my agent filed the losses under 'practice'.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
